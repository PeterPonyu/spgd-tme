Operator cost, measured on CPU with no accelerator anywhere in the protocol. Upper block: one openST 400-spot build decomposed into stages that do not overlap, so the stages sum to the build they decompose, each reported as the mean and standard deviation of five runs taken after a warm-up pass. The platform self-gate, which fits the per-gene platform factor on two held-out halves and retains only the fraction that transfers, is \(58.18\%\) of the build; the reportability gate that decides KEEP or ABSTAIN is \(0.001\) s, under \(0.01\%\) of it. Lower block: full-\(n\) \(t=0\) passes on each timed substrate, with spot count, wall-clock seconds, and the implied milliseconds per spot. The repeated batch in the upper block was measured on an Intel Core Ultra 9 275HX (24 logical CPUs, 62\,GiB RAM; Python 3.13); the lower block is an earlier single-machine run whose hardware was not recorded with it. The build is a reproducibility estimate for this hardware and input size rather than a performance guarantee.
