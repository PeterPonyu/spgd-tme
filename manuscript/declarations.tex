\paragraph{Data availability statement.}
This study is a reanalysis of published spatial transcriptomics data; no new data were
generated. The four-patient CosMx basal-cell carcinoma export that carries the wound
axis and the donor split is deposited at Zenodo, doi:10.5281/zenodo.14330691, and is
described in the accompanying report~\cite{Andreatta2024zenodo,Yerly2025preprint}. The
independent CosMx carcinomas, the HNSCC openST library, and the breast Xenium and
Xenium FLEX libraries are the public releases of their source
publications~\cite{He2022,Crowell2025preprint,Pei2025,Schott2024,Janesick2023}. Each
input file used here is pinned by SHA-256 in Table~\ref{tab:materials}, so a reader can
confirm byte identity with the deposited copy before rerunning. The analysis code, the
locked reference matrices, the plotted values behind every panel, and the scripts that
render the figures and tables are released with the manuscript.

\paragraph{Ethics statement.}
Ethical review and informed consent were obtained in the primary studies that generated
the tissue and are reported there~\cite{Yerly2022,Yerly2025preprint,He2022,Janesick2023,Schott2024,Crowell2025preprint,Pei2025}.
This work used only de-identified, already public data and did not recruit participants,
collect new specimens, or access identifiable information, so it required no additional
ethical approval.
