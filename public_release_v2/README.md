# SPGD-TME V2 reproducibility release

This release accompanies the revised Methods manuscript **Two locked operators report mixed-spot TME composition on CosMx carcinomas**.

It provides the review-build manuscript, separate point-to-point responses, the reviewer-facing rebuttal summary, the LaTeX source used for the manuscript, and a supplementary bundle containing the locked plot data, constants, rendering code, and table-generation code. The package contains no patient-level raw sequencing files and no private machine paths.

## Reproduction scope

The supplementary bundle reproduces the reported figures and tables from the released plot data. The manuscript records the exact boundary between the locked analysis capsule and any source-library or reference-building input that may require access permission. The package therefore supports independent inspection and render-level reproduction without redistributing restricted source data.

## Contents

- `manuscript/` — compiled manuscript PDF and source files.
- `responses/` — native LaTeX PDFs for Reviewer 1, Reviewer 2, and the Rebuttal Lighthouse.
- `supplementary/` — plot data, frozen constants, renderers, and table generators.
- `RELEASE_MANIFEST.txt` — semantic inventory of the public files.
- `RELEASE_SHA256SUMS.txt` — integrity digests for this release.

## Citation and use

Please cite the accompanying manuscript and the source datasets listed in its Data Availability statement. The code and derived plot data are released for inspection and reuse under the terms stated in `LICENSES.md`; source-library licensing remains governed by the original data providers.
