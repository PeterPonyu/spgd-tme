# Remote boundary — SPGT public leaf

Submission / workbench ≠ public GitHub. Do not `git add -A` this workbench
onto `SPGT-site`. Do not push the CBC capsule.

## MUST stay local

- This workbench (`src/`, `scripts/`, `data/`, `locks/`, `manuscript/`)
- Absolute machine paths
- Compute-queue notes and agent session files
- Invitation or venue-forward packaging
- Donor h5ad and CosMx export

## MAY be public

- `SPGT-site` static leaf only (object prose, people, protocol, bounds, no results)

## Operator

If a file would name a leftover paper, a compute box, or a harness, it does
not go on the public leaf.
